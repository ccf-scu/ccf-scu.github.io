# ccfweb 视觉母版分析与迁移规范

## 结论

`ccfweb` 的辨识度来自一套完整的叙事模板，而不是“黑色背景加蓝色按钮”：页面把一次访问组织成五个章节，在深色知识场、白色编辑页面、深色仪表和浅色档案卡之间切换。迁移必须同时保留空间节奏、标题比例、技术微排版和黑白章节对比；只复制颜色或圆角会失去原设计。

本次采用“视觉等价、架构原生”的方式：保留 Astro 内容模型、CMS、路由和可访问语义，迁移母版最终生效的设计规则，不整体复制约八千行包含废弃实验的 CSS，也不把母版中硬编码的内容和未实现后端带进正式站。

## 1. 视觉 DNA

### 色彩

| 角色 | 母版值/做法 | 正式站用法 |
|---|---|---|
| 纸张 | `#f5f5f2`、`#ecece7` | 普通章节、卡片周围的大面积留白 |
| 墨色 | `#111318`、`#2b2f38` | 正文、标题与深色按钮 |
| 夜色 | `#04060a`—`#080b12` | Hero、成就档案、Join、页脚 |
| 电蓝 | `#176bff`、`#74a0ff` | 焦点、状态、索引、交互反馈 |
| CCF 红 | `#d02b46` | 品牌标识中的第二强调色，不再作为大面积主色 |
| 辅助色 | 紫、绿、暖红 | 只用于活动类别和状态，不争夺电蓝主导地位 |

深色区域并非纯黑色块，而是由蓝色径向光、极低透明度网格、细边线和局部玻璃层构成。浅色区域也不是普通白底卡片流，而是带有细线、编号和大留白的编辑式版面。

### 字体层级

- 中文标题和正文以本地 `SCU CCF Sans` 为主，标题使用约 650—700 的重量和负字距；
- 关键概念或一个短语可用 `SCU CCF Serif`，母版只在 Hero 的“共振”和大引用中使用；
- 坐标、章节编号、状态和索引使用系统等宽字体、全大写、宽字距；
- Hero 标题桌面约 `clamp(4.4rem, 7.1vw, 7.8rem)`、移动约 `3.45—4.2rem`；章节标题桌面约 `3—5.5rem`，移动约 `2.5—3.2rem`；
- 正文保持 1.7—1.86 行高，用充足留白换取可读性，而不是缩小文字塞满页面。

### 空间与形状

- 最大内容宽度 1240px，桌面左右至少 32px，移动约 16px；
- 普通章节纵向留白约 110—150px，移动约 72—92px；
- 标题/说明常用 60/40 非对称双栏；
- 圆角分三级：14px 小控件、24px 卡片、38px 沉浸仪表；
- 线条多为 1px、低透明度；阴影集中在少数“仪器/档案”组件，普通文字区几乎不用阴影。

## 2. 页面叙事与构图

### Header

桌面采用三列布局：左侧三圆点品牌、中央导航、右侧语言/加入动作。位于 Hero 顶部时透明并使用白字，滚动后变为半透明纸张色和模糊背景。移动端只保留品牌、语言标识和圆形菜单按钮，菜单作为独立下拉面板。

正式站保留现有导航信息，但将“内容后台”处理为右侧胶囊动作；移动端菜单继续保留 Escape 关闭和滚动锁。

### Hero：知识共振场

- 至少一屏高，深黑蓝渐变；背景由细网格、节点/波纹和蓝色光晕组成；
- 左侧超大两到三行标题，最后关键词用蓝色衬线；
- 上下用坐标、实时状态、能量读数和交互提示形成“研究仪器”语义；
- 主按钮为白底黑字，次按钮为深色玻璃；
- 动效只是增强：静态背景、标题和动作本身已经构图完整。

正式站用轻量指针/键盘能量反馈和 CSS 场替代母版的大型 Canvas 物理模拟，减少前台脚本，同时保留视觉和交互意图。

### About：编辑式白页

第一屏以超大标题和右侧说明开场；下方左侧为蓝色“无限共同体”轨道图，右侧三条原则使用横线、编号、英文微标题和中文标题；末尾以大号衬线引用收束。这里不使用同尺寸卡片网格。

### Activities：可能性切片仪

白色章节标题下嵌入一个大号深色圆角仪表。左侧描述当前活动方向，右侧叠放四张带图片的档案卡，底部四个 Tab 是主要操作。类别颜色只影响局部光和当前索引。正式站将四类代表图片和最近活动入口接入内容数据，并保留按钮、键盘和无脚本可读性。

### Achievements：深色档案章节

整段切入深色背景。上方是大标题；中部左侧档案索引、右侧叠页；下方使用纵向时间轴。深色章节提供全页节奏反转，也是母版最重要的结构锚点之一。

### Open source 与 Join

开源模块是浅灰大卡片：左侧宣言，右侧仿仓库文件列表。Join 再次进入深色一屏，以巨大标题、同心圆“入口”、两枚按钮和三步路径结束；页脚继续使用同一夜色，不另造风格。

## 3. 响应式规则

- 1120px：压缩容器和复杂仪表尺寸；
- 920px：双栏开始收缩，Header 切换移动导航；
- 680px：所有章节单列，Hero 标题保持高冲击但控制换行，按钮纵向全宽；
- 活动仪表在移动端不是简单缩放：文字移至上方，卡片居中下移，Tab 保持四列；
- 成就档案的左右结构改为顺序阅读，时间轴年份仍保留在左侧；
- 360/390/430 均不得出现页面级横向滚动，44px 为交互目标下限。

## 4. 动效与无障碍

- Header 状态、Reveal、卡片切换使用 180—600ms 的缓动；
- Hero 的背景响应指针、触摸和方向键，但不劫持滚动；
- 活动 Tab 同步 `aria-selected`，内容变化通过可见状态表达；
- `prefers-reduced-motion: reduce` 下关闭持续动画、Reveal 位移和光晕移动；
- 无 JavaScript 时导航、四类活动内容、公开链接与正文仍然存在；
- 焦点使用清晰的电蓝外框，深色区与浅色区都达到可辨识对比。

## 5. 正式站映射

| ccfweb 母版 | Astro 正式站 |
|---|---|
| 固定 HTML 文案 | `homepage.yml`、`organization.yml`、内容集合 |
| 活动四张固定卡 | 按类别选择最近公开活动，缺失时用精选受控素材 |
| 成就固定档案 | `honors` 内容集合和公开迁移图片 |
| QQ 弹窗/报名占位 | 现有联系方式和关于页锚点，不引入业务后端 |
| GitHub 仓库预览 | `links.yml` 中的 GitHub 地址与当前路由清单 |
| 大型 Canvas/多套实验交互 | 单套轻量共振增强 + 活动切片切换 |
| 单页锚点导航 | 正式多页面导航，首页内部章节仍保留锚点 |

## 6. 不迁移的部分

- ccfweb CSS 中未被当前 HTML 使用的早期 hero、program explorer、prism 等重复原型；
- 中英文切换：当前内容和 CMS 尚无双语 schema，伪翻译会破坏内容契约；Header 可保留“SCU / CCF”技术标识而不提供无效按钮；
- 在线报名表和后端接口占位；
- 依赖鼠标悬停才能理解的说明；
- 空链接、占位按钮和没有替代文本的内容图片。

## 7. 验收方式

以 `../ccfweb/preview-desktop.png` 和 `preview-mobile.png` 作为构图参考，不要求逐像素复制，但必须在以下方面保持同一模板：黑白章节顺序、标题比例、技术微排版、蓝色强调、活动仪表、深色档案、开源卡片和 Join 结尾。自动验证之外，桌面及 360/390/430 截图需要人工对照，检查 Header、换行、图片裁切、长内容、焦点和无横向溢出。
