- [ ] 新维护者各自完成登录、草稿、预览、审核、发布、归档和回滚；
- [ ] 确认 OAuth 服务归属、域名、费用、Secret 轮换方法和故障联系人；
- [ ] 确认 Cloudflare Pages、自定义域名、分支保护、必需检查和备份策略；
- [ ] 复核网站联系人、指导老师、招新状态和友情链接；
- [ ] 复核图片授权与成员隐私，处理未确认资料；
- [ ] 演练 `INCIDENT_ROLLBACK.md`；
- [ ] 交接完成后撤销离任人员权限、旧 Token 和无用 App；
- [ ] 将交接日期、双方姓名和演练证据记录在非公开组织台账。
