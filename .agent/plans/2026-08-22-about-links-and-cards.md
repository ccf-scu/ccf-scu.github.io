# 关于分会链接模型与卡片视觉优化

## 目的与用户可见结果
允许相关链接使用 HTTP 或 HTTPS；后台将“关于分会相关链接”“首页开源按钮”“全站页脚链接”拆成清晰入口；关于页的分会原则、指导老师和相关链接卡片获得更明确、精致的视觉层级。

## 范围与明确不做
修改站点数据 schema、Decap 配置、首页/关于页/页脚消费者、关于页样式和维护文档。不改变 OAuth、内容集合、部署架构，不删除用户刚保存的链接或老师数据。

## 当前事实与相关文件
- `src/data/links.yml` 混合 `general/repository/footer` 三种用途，最新 HTTP 链接被 `src/lib/site.ts` 的 HTTPS-only 校验阻断。
- `src/pages/about.astro` 的三组内容共用基础 `.direction-card`，缺乏内容类型差异。
- `src/pages/index.astro` 与 `src/components/Footer.astro` 从混合链接列表选择各自链接。

## 验收标准
- `http://` 与 `https://` 外链均通过 schema，其他协议继续拒绝。
- 相关链接不再出现“类型/用途”字段；首页开源按钮和页脚链接在后台各有独立入口。
- 现有相关链接、GitHub 仓库入口与页脚行为迁移无丢失。
- 关于页桌面与移动端无溢出，三类卡片层次清晰且可访问。
- 文档、自动检查、浏览器截图、生产部署和线上冒烟完成。

## 分阶段步骤
1. 同步后台最新内容并建立独立数据文件与兼容迁移。
2. 更新 schema、CMS 配置及三个前台消费者。
3. 重构关于页卡片结构和响应式样式。
4. 更新文档并完成自动/浏览器验证。
5. 提交、发布并线上检查。
